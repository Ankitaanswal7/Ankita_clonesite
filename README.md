# 🛒 Amazon Clone Website

A front-end clone of the Amazon shopping website, built using **HTML and CSS**. This project recreates the look and feel of Amazon's e-commerce homepage, featuring a navigation bar, promotional banners, product categories, and a visually appealing shopping interface.

## 📌 Project Overview

The Amazon Clone is a front-end web development project created to practice and demonstrate fundamental web development skills. It replicates the layout and design of Amazon's homepage, providing users with a familiar online shopping experience.

The website showcases different shopping categories, including electronics, fashion, groceries, movies, pharmacy, travel, and more.

## ✨ Features

- **Amazon-Inspired Navigation Bar:** A navigation layout inspired by Amazon's homepage.
- **Search Bar:** A search interface for exploring products.
- **Product Categories:** Multiple shopping categories displayed through image cards.
- **Promotional Banner:** A hero section highlighting shopping offers.
- **Product Showcase:** Dedicated sections for different product categories.
- **Clean UI Design:** A structured and visually appealing interface.
- **Responsive Styling:** CSS-based styling for an organized webpage layout.

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| HTML5 | Website structure and content |
| CSS3 | Styling, layout, and visual design |
| Images (JPG/PNG) | Product visuals, banners, and branding |
